# Maxwell-Equations-Initial-Data-Construction
The observation of gravitational wave events marks a rapidly advancing frontier in modern astronomy, where accurate modelling of compact, high-mass systems plays a key role. In this project, we focus primarily on the 3+1 decomposition and the resulting constraint equations for Maxwell’s equations and in general relativity for the metric tensor and Einstein’s equations. We show how the electromagnetic constraints can be derived directly from the field-strength (Faraday) tensor. We also study the numerical implementation of Maxwell’s equations using two different simulation techniques and analyze the behaviour of the constraints, the associated residuals, and the computational complexity of each method.
